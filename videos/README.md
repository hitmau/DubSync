# Biblioteca local de vídeos

Vídeos baixados pelo DubSync ficam diretamente nesta pasta, com nome legível e ID do YouTube. O arquivo é somente vídeo, sem faixa de áudio. Arquivos de mídia e manifestos locais são ignorados pelo Git; mantenha aqui os originais para reproduzir e reprocessar.

Na interface, a aba **Arquivo** mostra o caminho, a origem do YouTube, a resolução e o tamanho. O botão **Abrir pasta de vídeos** abre este diretório no Explorer.
